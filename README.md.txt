# ResQ – Community Emergency Response and Support Application

## 1. Project Overview

ResQ is a C# Windows Forms desktop application designed to improve community emergency response and support. It connects residents who need assistance with community volunteers who are willing to help.

The application provides a structured platform for submitting emergency assistance requests, reporting incidents, checking area risk levels and accessing emergency contacts and shelters.

ResQ supports three user roles:
- Resident
- Community Volunteer
- Administrator

The project supports **Sustainable Development Goal (SDG) 11: Sustainable Cities and Communities**, particularly Target 11.5.

## 2. Main Features

- User Login and Registration
- Resident Home Page
- Emergency Assistance Requests
- Request Status Tracking
- Incident Reporting
- Community Volunteer Request Feed
- Volunteer Request Status Updates
- Area Risk Dashboard
- Emergency Contacts and Shelters
- Administrator Dashboard
- Risk Level Management
- Incident Review
- Directory Management
- Request Monitoring
- Safety Log and Summary Report

## 3. System Requirements

The following software and environment are required:

- Windows operating system
- Visual Studio with .NET desktop development workload
- .NET 10 SDK
- SQLite database support

## 4. How to Open the Project

1. Clone the ResQ-Phase2 repository from GitHub.
2. Open the downloaded project folder.
3. Open the ResQ.slnx solution file in Visual Studio.
4. Allow Visual Studio to restore the required packages.

## 5. How to Build the Project

1. Open the solution in Visual Studio.
2. Select Build from the top menu.
3. Click Build Solution.
4. Alternatively, press Ctrl + Shift + B.
5. Check the Error List to ensure the project builds successfully.

## 6. How to Run the Application

1. Open the ResQ solution in Visual Studio.
2. Ensure the project builds successfully.
3. Press F5 to run the application.
4. The ResQ Login screen should appear.
5. Log in using an appropriate seeded demonstration account.

## 7. Simulation Disclaimer

ResQ is an academic project developed for demonstration and educational purposes. It uses a local database to simulate community emergency response activities.

It is not a live emergency response service. It does not provide real-time emergency notifications or dispatch emergency personnel. Users should contact the appropriate emergency services during actual emergencies.
